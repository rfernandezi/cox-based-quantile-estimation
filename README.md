# Cox-based quantile regression estimator

R scripts used to reproduce the Monte Carlo simulations reported in:

Fernández-Iglesias et al.
"A semiparametric estimator for quantile regression based on Cox proportional hazards models"

## Files

cox_qr_estimator.R  
Implementation of the proposed estimator.

simulation_models.R  
Data generating mechanisms.

simulation_errors.R  
Simulation study for estimation error.

simulation_coverage.R  
Simulation study for bootstrap CI coverage.
